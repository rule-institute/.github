# Contributing to Rule Institute

Rule Institute is in early shaping; the contribution model will be documented
once the structure stabilizes.

For now, contributions are coordinated directly with the maintainers. If you
have a suggestion, file an issue on the relevant repo or reach out to discuss.

## Skill changes

Changes to skills under `rule-institute/Skills/` follow the same lifecycle
discipline as the swift-institute ecosystem — see the `skill-lifecycle` skill
for `[SKILL-CREATE-*]` and `[SKILL-LIFE-*]` rules. The
`[SKILL-CREATE-013]` description-length ceiling (≤ 250 chars) applies to all
skills in this org.
